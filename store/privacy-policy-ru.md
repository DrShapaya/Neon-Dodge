# Политика конфиденциальности приложения Neon Dodge

Дата вступления в силу: 28 октября 2026 г.

Приложение Neon Dodge (далее — «Приложение») хранит игровой прогресс локально
и использует Yandex Mobile Ads SDK для показа рекламы. Для загрузки рекламы
нужен доступ к сети.

## Какие данные обрабатываются

Приложение не отправляет игровой прогресс на свои серверы. На устройстве
локально в SharedPreferences сохраняются только игровой прогресс,
рекорды, история забегов, настройки звука и вибрации, выбранные скины и факт
прохождения обучения. Эти данные удаляются вместе с приложением.

Yandex Mobile Ads SDK может обрабатывать технические данные устройства,
идентификаторы рекламы и сведения, необходимые для показа и измерения рекламы,
в соответствии с политикой конфиденциальности Яндекса.

## Разрешения

Приложению требуются `android.permission.VIBRATE` для тактильной обратной связи,
`android.permission.INTERNET` и `android.permission.ACCESS_NETWORK_STATE` для
загрузки и проверки доступности рекламы.

## Сторонние сервисы

В приложении используется Yandex Mobile Ads SDK. Условия обработки данных
рекламой определяются политикой конфиденциальности Яндекса.

## Дети

Приложение не запрашивает имя, контакты или содержимое устройства. Реклама
может использовать ограничения и настройки, применимые к детским пользователям,
на стороне рекламной сети. Покупок в приложении нет.

## Изменения политики

Актуальная версия политики публикуется по адресу, указанному в карточке
приложения. При изменении функциональности, связанной с обработкой данных,
политика будет обновлена.
