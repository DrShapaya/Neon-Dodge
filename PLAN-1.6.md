# Neon Dodge 1.6 — план обновления

Дата: 22.10.2026  
Основа: разбор кода версии 1.5 (`GameView`, `Progress`, `MainActivity`,
манифест, Gradle, store-ассеты, содержимое APK).  
Статус: этапы 1–2 закрыты, этап 3 в работе: добавлены рекорды по режимам,
пост-90-секундное давление, «Испытание дня», сохранение `quest_ids` и

`versionName = 1.6`; release-APK 227 042 байта, R8 и `shrinkResources`
включены.

## Как ведём работу

- Делаем по одному этапу, после каждого — сборка, проверка и отметка в этом
  файле.
- Не ломаем сильные стороны: офлайн, без рекламы, без `INTERNET`, только
  `VIBRATE`, процедурная графика на `Canvas`, компактный APK.
- Новые функции не добавляем, пока не закрыты критичные баги.
- Версию поднимаем только перед релизом: `versionCode = 7`,
  `versionName = 1.6`.

- [x] **Predictive back на Android 16.** Для `targetSdk 36` на Android 16
  `onBackPressed()` не вызывается. Нужно зарегистрировать
  `OnBackInvokedCallback` для API 33+ и оставить fallback для API 26–32.
  Файлы: `MainActivity.java`, `AndroidManifest.xml`.
- [x] **Рекорд при выходе в меню.** `gameOver()` обновляет `progress.best`,
  а `resetMenu()` — нет. Исправить в `bankScore()`/`resetMenu()`, вызвать
  `checkProgress()`, чтобы достижения «Счёт 1000/5000» тоже открывались.
  Файл: `GameView.java`.
- [x] **Рекорд в «Дзене».** После исправления выше рекорд должен сохраняться
  и при выходе из «Дзена» через паузу.
- [x] **Приватность backup.** Поставить `android:allowBackup="false"` и
  `android:fullBackupContent="false"`, чтобы `SharedPreferences` не уходили
  в системный backup/перенос. Позже — ручной экспорт/импорт.
- [x] **Мелочи манифеста.** Добавить `android:isGame="true"` (Game Dashboard)
  и `android:enableOnBackInvokedCallback="true"`.
- [x] Проверить сборку после этапа: `.\gradlew.bat assembleDebug` — успешно.
