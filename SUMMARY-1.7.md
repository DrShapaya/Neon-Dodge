# Neon Dodge 1.7 — сводка релиза

Версия 1.7 — актуальная сборка Android-игры `com.isaev.neondodge`.

- `versionCode = 8`, `versionName = 1.7`
- minSdk 26, targetSdk 36
- Три режима и испытание дня
- Девять типов астероидов, мини-боссы на 2/4/6 минуте и восемь бонусов
- Независимые звёздный и близкий множители; щит сохраняет множители
- Ежедневные задания, достижения, неон, восемь скинов сферы, семь шлейфов,
  статистика и история забегов
- Две музыкальные темы, чередующиеся между забегами
- Полностью офлайн, разрешение только `VIBRATE`
- APK: `dist/NeonDodge-1.7.apk`

Скриншоты 1.7 сняты через `adb screencap` с запущенного APK и включены в README
и комплект карточки релиза.

Перед публикацией в RuStore нужно указать контактный e-mail и публичный URL
политики конфиденциальности. Для повторной съёмки кадров добавлен
`tools/capture-screenshots.ps1`, который устанавливает APK через ADB и сохраняет
кадры непосредственно с экрана приложения.
